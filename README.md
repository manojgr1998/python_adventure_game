# python_adventure_game
Building a Python Adventure Game with GitHub Copilot

Python Adventure Game

A simple text-based adventure game built using Python and assisted by GitHub Copilot.

📌 Overview
This project is a beginner-friendly text-based adventure game where the player explores different locations, makes choices, and attempts to find a legendary treasure.
The game demonstrates core Python concepts, including:
•	Functions
•	Variables & user input
•	Conditional statements
•	Loops
•	Reusable helper functions
The development was accelerated using GitHub Copilot, which helped generate function structures, suggest logic improvements, and streamline repetitive code.
________________________________________
🎮 Gameplay Description
You play as an explorer searching for a legendary treasure hidden in an ancient land.
The game flow includes:
•	Entering your name
•	Choosing an initial path: Dark Forest or Mysterious Cave
•	Making strategic decisions in each location
•	Experiencing one of three outcomes:
o	Win → You find the treasure
o	Lose → A wrong choice ends your adventure
o	Restart → You can play again anytime
Every decision changes the direction of your story.
________________________________________
✨ Features
•	Fully interactive command-line interface (CLI)
•	Branching story paths with multiple endings
•	Clean modular design using functions
